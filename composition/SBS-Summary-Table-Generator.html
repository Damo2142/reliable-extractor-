📋 How to Use ▼
1
In RC Studio, create a new animation and select Table-External-01-V02.js as the script file.
2
Prepare your Excel file with Device (BACnet device ID) and Controller Name as the first two columns. Add one column per data point you want to display — use the BACnet object code as the cell value (e.g. AV9, AI2, BO1, MV16). Column headers become the table column headings.
3
Upload the Excel file here, set options, and click Generate JSON Files. Two files will download: table-config.json and table-settings.json.
4
In RC Studio animation, click Import and select table-settings.json.
5
Click Attributes. On row 2 (Table Config File), select table-config.json. Set Font to Calibri, Heading alignment Center/Middle.
6
If using Communication Status: link the Vendor ID Value of 0= Not Communicating state colors to {'{device}'}DEV{'{device}'}:120 — value >0 = Communicating, 0 = Not Communicating. Hit OK and send to system.
